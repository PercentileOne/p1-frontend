Phase 2 Expansions

FUTURE · POST-MVP
🚌
Service Bus Fan-Out
At 1M candidates, the timer function publishes one message per candidateId to a queue. Each agent picks up its own message independently — isolated, retryable, horizontally scalable. Growth, Opportunity, and Coach all run in parallel per user.
Azure Service Bus · Topic per agent type
🔎
Azure AI Search Index
Opportunity Agent moves from stub to real job board scanning. An indexer runs over job board APIs (Reed, LinkedIn, Glassdoor) and populates a vector search index. The agent runs semantic search against the candidate's profile embedding.
Azure AI Search · Vector + semantic
🧠
Claude-Powered Coaching
Push Coach replaces the static template with a Claude API call. The prompt includes the full UserAgentDocument as context — scores, views, nudges, match history — so every question is uniquely personalised to that candidate's exact situation.
claude-sonnet-5 · Structured output
