# P1 Cockpit Specification v1.1
*A structured, foundational specification for the Percentile.One Cockpit Experience*

## 1. Purpose of the Cockpit
The P1 Cockpit is the user's Home — the central hub of their life and professional operating system. It provides:
- A personalised daily overview
- A unified view of tasks, goals, health, and progress
- A dynamic, agent‑powered interface
- A persona‑aware, tenant‑aware experience
- A living, breathing UI that adapts to the user

The cockpit is the heart of P1.

## 2. Primary Navigation Stack (Top Section)
These four nodes sit above Life Areas and represent the core loop of P1:

### 2.1 Home
Loads the cockpit (current screen).

### 2.2 Today
Shows the user's plan for the day.

### 2.3 Chat
AI chat interface with recent and saved conversations.

### 2.4 Goals
Long‑term goals, progress, predictions, and milestones.

## 3. Life Areas (Left Sidebar)
Persona‑aware, dynamically generated categories such as:
- My Life
- My Profession
- Health
- Finances
- Home Admin
- Study / Learn
- Family
- Bills
- Projects
- Planning
- Admin
- Vault (Life Info)

Sidebar must be resizable (drag to widen/narrow).

## 4. Top Navigation (Center‑Right Cluster)
Global items:
- Jobs
- Shop
- Contacts
- Messages
- Feed
- P1 Logo (steps inside circle)

## 5. Cockpit Layout

### 5.1 Greeting Row
Personalised greeting with contextual intelligence.

### 5.2 Overview Cards
Four compact cards:
- Top 3 Tasks
- This Week
- Meal Plan
- Exercise

Each card has its own Agent controlling subtle motion.

### 5.3 Activity Grid
8 metrics, 2 rows:
- Tasks Done
- Habit Streak
- Water Intake
- Sleep Avg
- Deep Work
- Steps
- Goals Progressed
- Health Metrics

### 5.4 Quote of the Day
Agent‑powered, rotates daily.

### 5.5 News Section
Tabs:
- Industry
- World
- Local
- Sport
- Weather

### 5.6 Video Agent Section
Curated videos based on goals, health, profession, interests, family, location, and aspirations.

## 6. New Sections to Add

### 6.1 Goals Summary Panel
Shows momentum, streaks, predictions, and milestones.

### 6.2 Salary Trajectory Graph
A signature P1 feature showing:
- Starting point
- Current point
- Expected trajectory
- Long‑term goal
- Flashing silver dot that moves with every positive action

## 7. Agents & Representatives
Every major node has:
- **Agent** (background intelligence)
- **Representative** (user‑facing insights)

Examples:
Finance Agent, Health Agent, Study Agent, Career Agent, Home Admin Agent, Bills Agent, Planning Agent, Video Agent, UI Agent, Chief UI Agent.

## 8. Persona System
Personas include:
- Student
- Professional
- Athlete
- Entrepreneur
- Parent
- Tradesperson
- Designer
- Nurse
- Lawyer
- Housewife/Husband

Persona determines:
- Sidebar nodes
- Feed content
- Video recommendations
- Tone of greeting
- Goals
- Insights
- Agents activated

## 9. Tenant System
Tenants include:
- Universities
- Companies
- Sports clubs
- Organisations
- Demo tenants (for YC)

Tenant determines branding, data sources, and synthetic demo data.

## 10. Login Screen (v1)
Fields:
- Username
- Password
- Organisation / Tenant
- Persona

After login:
- Persona Initialisation Agent activates
- Synthetic or real data loads
- Cockpit appears

## 11. Life Info Vault
A secure node for:
- Passport
- Driving license
- Insurance
- Subscriptions
- Renewals
- PINs
- Important dates

## 12. Groups
Groups based on profession, university, team, organisation, or interest.

## 13. Advertising (Ethical)
Agent‑powered recommendations:
- Best ISA
- Best mortgage
- Best savings
- Best insurance

## 14. UI Behaviour
The cockpit must feel alive:
- Cards pulse
- Quotes fade
- News updates
- Graphs shift
- Agents animate subtly
- Chief UI Agent monitors activity
