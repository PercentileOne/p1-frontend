InterviewMe · Infrastructure Reference

Every moving part, for the load test

What actually runs when a candidate takes an interview — what each piece does, who's billed for it, and whether it scales on its own or needs watching at 100–200 concurrent sessions.

Snapshot taken 2026-09-06, ahead of the Azure Load Testing pass on /api/ai-proxy, the transcribe proxy, and the upload endpoint.

Found while building this table — fixed same day

The ElevenLabs API key was baked into the public JS bundle on both the candidate and recruiter portals — VITE_ELEVENLABS_API_KEY was a build-time variable, which Vite exposes directly to the browser. Same class of issue as the OpenAI incident already on file. Fixed by adding Explain.Api's /interviews/speak proxy (same pattern as the existing Lessons/ReadAloud feature) — the key and voice-id mapping now live server-side only, and all three client call sites (candidate portal, recruiter portal, and a third ad-hoc call in LeagueTable.tsx) go through it. The old exposed key was deleted from ElevenLabs the same day.

AI & voice providers
called by the backend per question, per answer, per spoken line
PartWhat it doesOwner / billed toFor the load test
Azure AI Foundry Model Router
/api/ai-proxy		 Generates every interview session (questions, MCQs, Sarah/James/Mike's scripts), scores every answer, drives Learn lesson generation. Routes across 20+ models with automatic failover. Azure AI FoundryPer-token, your Azure subscription ◐ Check quota/TPM
OpenAI Whisper
/api/ai/transcribe		 Transcribes every spoken answer. Calls api.openai.com directly — not routed through the Model Router, so it has none of that failover. OpenAIPer-minute of audio, direct OpenAI billing ◐ Single point of failure
ElevenLabs TTS
/interviews/speak		 Generates Sarah, James, and Mike's actual spoken voice audio. Proxied through the backend (see finding above) — key and voice ids held server-side, results cached in Blob Storage. ElevenLabsPer-character, direct ElevenLabs billing ◐ Own rate limit

These three are the ones actually worth watching under load — each has its own separate quota/rate-limit ceiling, independent of how the App Service or Cosmos hold up.
