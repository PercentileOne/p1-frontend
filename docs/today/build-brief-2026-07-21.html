The Big Picture — What Changed and Why

The product was previously called TalkToLearn — an AI-powered learning app built around the Feynman Technique (you only understand what you can explain out loud). The name has been officially changed to Explain. The domain explain.global is live and the coming soon page is already attracting organic traffic from the US, UK, Italy and Taiwan with zero marketing.

Alongside Explain (the learning product), a second product has been scoped and is now in active development: the Explain Recruiter Portal — a B2B tool for recruitment agencies to build AI-powered interview packs, conduct live phone interviews with answer capture, and score candidates automatically. The first pilot agency is Vallum Associates. Both products sit under the Percentile.One platform umbrella.

Platform Architecture — The Unified Model
🏗️

Workspace-First Platform Identity

New Decision

Inspired by how Slack, Notion, Linear and GitHub handle multi-product identity. Every user belongs to a Workspace — the top-level unit for billing, members, and product access.

  • Workspace type: Personal — an individual using Explain to learn (B2C)
  • Workspace type: Organisation — a company using the Recruiter Portal (B2B)
  • One login works across all Explain products — no separate accounts per product
  • Billing, subscriptions, and team members all attach to the Workspace
  • A user can belong to multiple Workspaces (personal + employer's org)
🗄️

Cosmos DB — 5 Containers, Serverless

Designed

Decision: 5 separate containers (not one shared container) so each entity type can scale independently. All on serverless throughput — zero minimum cost, pay per request, switch to provisioned when scale demands it.
