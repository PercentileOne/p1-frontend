# 1. Introduction

## 1A. What Percentile.One Is

Percentile.One (P1) is a Cognitive Operating System — a unified, AI-augmented learning platform that transforms how students learn, how teachers teach, how parents monitor, and how institutions evaluate cognitive progress. It is not a quiz app, a flashcard tool, or an LMS. It is a complete knowledge-to-mastery pipeline, built to serve every stakeholder in the modern education ecosystem.

P1 converts raw learning inputs — handwritten notes, lecture audio, PDFs, textbook content — into structured, adaptive study material: cards, concepts, tests, learn modes, and readiness scores. It then tracks mastery over time, surfaces weak areas, and orchestrates the student's study agenda to maximise cognitive output.

Every module connects. Every action compounds.

## 1B. Why It Exists

The current education technology market is fragmented. Students use five different apps to do what P1 does in one. A flashcard app here. A note-taking app there. A revision scheduler somewhere else. A mock exam platform. A parent-monitoring tool. None of them talk to each other. None of them share a cognitive model. None of them produce a unified mastery score.

P1 exists to collapse the stack.

## 1C. The Problem It Solves

| Problem | How P1 Solves It |
|---|---|
| Students don't know what to study | Readiness Engine ranks content by urgency and gap |
| Notes are never revisited | AI Notes Engine converts them into cards and learn modes automatically |
| No feedback loop between study and exam | Test Engine generates targeted tests from actual study material |
| Parents can't see real progress | Parent Dashboard shows real-time mastery, streaks, and focus |
| Teachers have no cognitive view of the class | Teacher Tools surface heatmaps, readiness rings, and weak-area alerts |
| Universities can't assess applicant depth | University Mode provides permissioned cognitive profiles |
| Revision is passive and inefficient | Active recall, spaced repetition, and concept testing built in |
| Learning is solitary | Multiplayer, Groups, and shared cards enable social learning |

## 1D. The Cognitive Layer

The Cognitive Layer is the intelligence backbone of P1. It sits beneath every user-facing feature and performs continuous cognitive profiling:

- **Ingestion** — notes, voice, PDFs, books, imports
- **Extraction** — concepts, definitions, key points
- **Structuring** — AI-generated notes, learn modes, cards
- **Testing** — concept tests, mock exams, targeted quizzes
- **Scoring** — mastery scores, readiness percentages, consistency ratings
- **Routing** — study queue priority, weak area detection, personalised paths
- **Reporting** — streaks, improvement rates, deep work sessions

The Cognitive Layer is what makes P1 fundamentally different from every other platform. It does not wait for the student to do the right thing. It orchestrates the right thing automatically.

# 2. Platform Philosophy

## 2A. Core Principles

**1. Every input becomes an output.**
Anything a student puts into P1 — a voice note, a scribbled thought, a PDF — must emerge on the other side as structured, testable knowledge. Nothing is a dead end.

**2. Mastery, not completion.**
P1 does not track whether a student finished a unit. It tracks whether they have genuinely mastered it. Completion is a proxy. Mastery is the goal.

**3. The platform works for every stakeholder.**
A student, a teacher, a parent, a university admissions officer, and an employer should all find P1 indispensable — for different reasons. The platform creates value at every node of the education ecosystem.

**4. Cinematic without friction.**
The UI must be beautiful enough to command attention, simple enough to disappear when the student is focused, and fast enough that it never interrupts cognitive flow.

**5. AI is infrastructure, not a feature.**
AI in P1 is not a chatbot, not a button, not a novelty. It is woven into every pipeline — transcription, summarisation, concept extraction, question generation, readiness scoring, and content reconstruction. It is invisible and indispensable.

## 2B. Design DNA

P1's visual identity is built on five principles:

- **Dark cinematic backgrounds** — `#0a0b10` base, `#0f1117` surface, `#13151c` elevated
- **Gradient accent cards** — each subject domain has a distinct gradient persona
- **Micro-typography precision** — every size, weight, and contrast level is deliberate
- **Motion with physics** — spring-based animations, not CSS easing
- **Hierarchy through light** — information importance is communicated via luminance, not size alone

## 2C. The Anti-Features

P1 deliberately does not include:

- Gamification for its own sake (badges, XP, leaderboards that don't drive mastery)
- Passive video consumption without active recall
- Algorithm-driven content feeds unrelated to the student's study agenda
- Social media mechanics that distract from learning

## 4B. Core Systems

### Learning Centre
The student's primary workspace. Contains all study tools — cards, notes, books, queue, groups, certifications. Every module here feeds into and receives from the Cognitive Layer.

### Cognitive Layer
The intelligence backbone. Processes all inputs into structured outputs. Maintains mastery scores, readiness percentages, concept graphs, and study agendas. Invisible to the student; omnipresent in their experience.

### Study Pipeline
The end-to-end flow from raw input to mastered knowledge:
> Voice / Notes / PDF / Book → Ingestion → AI Structuring → Cards → Learn Mode → Test → Readiness Score → Study Queue

### Readiness Engine
Calculates a single readiness percentage per topic and per overall study profile. Weights: consistency (30%), improvement rate (25%), deep work sessions (20%), mock exam performance (15%), concept mastery (10%).

### Persona Shells
Separate authenticated contexts for parents, teachers, universities, and employers. Each shell provides a role-appropriate view of student cognitive data, with permissions controlled by the student.

## 5.02 — Cards


### Section 1 — Overview
Cards are the atomic unit of knowledge in P1. Each card represents a discrete, testable concept — a topic with a title, description, difficulty level, mastery score, and a set of extracted concepts. Cards can be studied, tested, and reviewed. They accumulate mastery scores based on repeated active recall.

**Navigation:** `/learning/cards`  
**Who uses it:** All learners  
**Problem it solves:** Information stored in notes is passive. Cards force active recall — the single most evidence-backed study technique.

### Section 2 — Feature List
- Gradient-branded card tiles with subject colouring
- Mastery ring per card (0–100%)
- Difficulty level (1–5 dots)
- Last-tested timestamp
- Concept count badge
- Study mode entry (Learn Mode, Test Mode, Quick Recall)
- Card filtering by subject, mastery, and difficulty
- AI-generated cards from notes, books, and voice recordings
- Card overlay (full-screen study experience)
- Score tracking per study session
- Integration with Study Queue for spaced repetition

### Section 3 — Benefits by Persona
- **Students:** Active recall replaces passive re-reading; mastery is measurable
- **Teachers:** Assign specific cards to students; track which concepts are weak
- **Parents:** See which cards a child has studied and at what mastery level
- **Universities:** Card mastery data feeds the cognitive profile
- **Employers:** Assign assessment cards to candidates

### Section 4 — Strategic Value
Cards are the engine of P1's mastery model. Without cards, there is no testable output. Every other module exists to generate or improve cards. The card library is also the primary driver of engagement — users return to check mastery scores, retake failed cards, and unlock new content.

### Section 5 — Monetisation Potential

# 9. Appendix

## 9A. Glossary

| Term | Definition |
|---|---|
| **Cognitive Layer** | The AI intelligence backbone of P1 that processes all inputs into structured, testable knowledge outputs |
| **Mastery Score** | A 0–100% score per card or topic, reflecting the depth and consistency of a student's knowledge |
| **Readiness Score** | A composite score reflecting a student's overall preparedness for assessment, weighted across consistency, improvement, deep work, mock exams, and mastery |
| **Active Recall** | A learning technique in which the student retrieves information from memory rather than reviewing it passively — the most evidence-backed study method |
| **Spaced Repetition** | A scheduling technique that presents material at increasing intervals based on how well it is remembered — optimises long-term retention |
| **Concept** | A discrete, testable knowledge unit extracted from a note or card — the atomic element of the P1 knowledge model |
| **Card** | A study object in P1 containing a title, subject, description, difficulty level, mastery score, and a set of extracted concepts |
| **Learn Mode** | A structured, section-by-section reading experience for a card's content — the comprehension gate before testing |
| **Test Engine** | The active recall and assessment system that generates questions from card concepts and scores student responses |
| **Voice Notes Engine** | The audio-to-knowledge pipeline that transcribes voice recordings and converts them into structured study material |
| **AI Notes Engine** | The intelligence pipeline that converts raw notes (typed, voice, OCR, or imported) into structured, headed, exemplified study material |
| **Readiness Engine** | The composite scoring system that calculates readiness percentages across five weighted dimensions |
| **Study Queue** | The priority-ordered agenda of cards and topics to study, ranked by the Readiness Engine |
| **Cognitive Profile** | A longitudinal record of a student's study behaviour, mastery scores, consistency, and deep work — shareable with universities and employers |
| **Heatmap** | A teacher-facing visualisation showing mastery scores per student per topic — formatted as a colour-coded grid |
| **Deep Work Session** | A study session lasting more than a defined threshold (e.g., 45+ minutes) of uninterrupted, active study — a premium signal in the Readiness Engine |
| **Admissions Engine** | The university-facing ranking algorithm that scores applicant cognitive profiles across five weighted dimensions |
| **P1 Certification** | A P1-issued credential confirming that a student has achieved a defined mastery threshold for a specific subject or skill set |
| **Transcript** | The cleaned, punctuated text output of the Voice Notes transcription pipeline |
| **blob: URL** | A browser-local audio URL generated from the MediaRecorder API — enables audio playback without backend storage |
| **Filler Words** | Words removed during transcription cleaning: um, uh, er, like, you know, I mean, sort of, kind of |
| **NoteSourceType** | The type classification of a note: typed · voice · scan · pdf · image · import · mixed |
