Three-Layer Enforcement
Layer 1
Route Guard
Every portal route is wrapped by <PortalGate>. Missing permission → immediate redirect to defaultPortalForPermissions(). No flash of protected content.
Layer 2
API Middleware
Every API endpoint declares a required permission string. The server resolves the session token → roles → permissions before any handler runs. HTTP 403 on mismatch.
Layer 3
UI Gating
Feature-level controls (buttons, tabs, panels) use usePermissions(). Unauthorised elements are removed from the DOM, not just hidden with CSS.
