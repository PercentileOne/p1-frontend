The agent-driven feed

A personal feed on the WORK tab: books, courses, videos, articles and real success stories for each person's career, found and checked by agents, ranked for each person, and improved by what people like.

The one rule: curated, not made up.

Agents find, check and summarise real things. They never invent people, quotes, stories or reviews. Everything an agent writes is labelled as curated by TheInterviewChair. Real user success posts join later, only when the user opts in.

Why it matters: with no users yet, the first content has to come from outside the platform. Made-up success stories would break trust the first time someone noticed, and UK rules on fake reviews and testimonials are strict.

The subject map

A ranked list of the best subjects for each profession. Questions of the day, posts, books, courses and videos are all made from it, so the feed is never random and the cost per subject is known.

1. Professions

From the careers catalogue and from the job titles people actually practise on.

2. AI proposes

The top subjects for each profession: core skills and the topics interviewers ask about.

3. Real data weights them

What our users practise on (the admin Subjects page), plus public occupational skills datasets, which are candidates to check for licence and fit, for example O*NET and ESCO.

4. A person reviews

Francis can judge software and cloud. Other professions need a reviewer or a trusted source. After that, an agent proposes a monthly refresh for approval.

5. Stored as subjects

Profession, subject, weight, why it matters, sources, last reviewed.

6. Looping

The curator agent works down each profession's subjects in turn, so every profession gets coverage and the most valuable subjects get the most content.

This also fits the micro-subjects idea: people search for and share narrow subjects, and each subject becomes something the feed can show.

General subjects, not tied to a profession

Success and learning content that suits everyone matters as much as profession content, so it has its own list. These are shown to everyone, ranked by each person's own likes and saves, and they take a share of every feed.

Videos

Videos like pitch moments and "turned down, then built a huge company" stories are the strongest part of a success feed.

Where LinkedIn's videos come from

Most are uploaded straight to LinkedIn by people, pages and media brands, then shown in LinkedIn's own player: autoplay on scroll, muted, captioned, cropped for the feed. The look is a player and layout choice, not a different source.

LinkedIn offers no library of its videos for other sites, and copying from it breaks its terms, so we can't take videos from where LinkedIn gets them.

What we can do legitimately

  • Embed videos from official channels through the official player, where the owner allows it
  • Build our own look (card, progress bar, autoplay on scroll) around the embed, without hiding its controls or branding
  • Use platform-native videos: real users' shared results, with consent
  • Link out to a clip that has no embed, with our own summary
  • Consider licensing later if one source becomes important

Before building

  • Read the current embed terms of each video source
  • Check, channel by channel, that embedding is switched on
  • Tag clips by theme so each person's ranking learns what they respond to

How it works

Content is made per topic and ranked per person. A few hundred topics a few times a day keeps model cost small and predictable, and each person's feed still feels personal.

flowchart LR
  SRC["Real sources - book database, official video channels, RSS, careers data"] --> CUR["Curator agent"]
  CUR --> VER["Verifier agent"]
  VER --> WRI["Writer agent"]
  WRI --> Q["Approval queue"]
  Q --> FI["Feed items in Cosmos"]
  FI --> RNK["Ranker"]
  PROF["Profile skills and career"] --> RNK
  RNK --> FEED["Person's feed on WORK"]
  FEED --> EV["Events - view, like, save, click, hide"]
  EV --> LRN["Learning loop"]
  LRN --> RNK
  LRN --> CUR
  CUR -.-> LOG["Agent message log"]
  VER -.-> LOG
  WRI -.-> LOG
  LOG --> DASH["Agent dashboard"]

Ranking, first version. Match to the person's skills and career, plus freshness, plus how well the item has done with similar people, plus a little variety so the feed does not narrow. Model re-ranking can come later. Approval. At first Francis approves in batches in the admin portal. Safe types, such as verified books and courses, can auto-publish later with spot checks.

Data

feed-items

  • type, title, summary, link, source
  • topic, skill and career tags
  • which agent made it, model, tokens, cost
  • verification result and status: draft, approved, published, retired

feed-events

  • user, item, event: view, like, save, click, hide
  • time spent and when
  • feeds the learning loop

agent-runs and agent-messages

  • each run's input, tools used, output, tokens, cost
  • each message one agent sends another
  • powers the dashboard

The agent dashboard

A staff page extending the Activity Log.

Activity

  • Runs per agent, items created, approval rate, errors
  • Source health: dead links and rejected items

Cost

  • Tokens and cost per agent and per item type
  • Spend against a daily budget

Learning

  • Engagement by item type and by source
  • Current topic and type weights

Agent conversations

  • Agents pass work through a queue and every message is logged
  • For example: "Curator sent 12 items to Verifier. Verifier rejected 3 for dead links."

Control

  • Pause one agent or all agents
  • Approve or reject items in batches

Rules the agents run under

  1. Agents use tools (existing endpoints and the data stores). They do not own systems.
  2. No agent holds a provider key. AI calls go through the Model Router on the backend.
  3. Every run is logged with its cost, and every agent has a daily budget and a kill switch.
  4. Nothing is published without verification, and anything uncertain waits in the approval queue.
  5. Personalisation uses only profile and in-product behaviour, is explained to the user, and can be switched off.
  6. Everything agent-made is labelled.

Tiers, as a starting idea. Standard: the curated feed ranked by career and skills. Premium: a personal agent with saved reading lists, weekly digests tied to interview dates, and deeper personalisation.
